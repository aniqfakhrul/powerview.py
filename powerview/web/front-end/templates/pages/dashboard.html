Collection scope & interpretation 0 of 4 sources loaded

This snapshot covers objects visible to the connected session in the current domain. It is a configuration review, not proof of exploitability or a complete security assessment. Zero matches does not establish that a domain is secure.

Counts include all returned objects; evidence is limited to the first 100 matches per signal. Signals can overlap. Only accounts with a readable, enabled account-control value enter the review queue. Missing attributes may reflect permissions. Last-logon signals use replicated lastLogonTimestamp and are approximate; missing timestamps are not treated as inactivity.

Collection uses read-only directory queries. Opening the page may reuse cached results; Refresh reads fresh values from the directory. It does not request tickets, retrieve password secrets, test credentials, or make directory changes. Refresh is manual.
